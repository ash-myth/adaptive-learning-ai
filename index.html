Hybrid Engine Architecture
Multi-Stage Cascade & Dynamic Switching Hybrid
Stage 1: Retrieval (Content & Lexical Hybrid)
Candidates = Top-300 SBERT (384d dense) ∪ Top-150 BM25Okapi (lexical)
Filters 13,618 catalogue courses to ~120 goal-aligned candidates
Stage 2: Ranking (Personalized & Fallback Hybrid)
• Cold-start (n=0): 0.70×Semantic + 0.20×BM25 + 0.10×Pop
• Onboarding (1≤n<5): Linear ramp (Δ +0.20 CF weight / session)
• Warm user (n≥5): 1.00 × NMF-CF (k=50 latent factors)
• Zero-CF fallback: Dynamic switch to semantic blend if CF < 1e-6
Stage 3: Diagnostic & Safety Layer (Explainable AI)
• Cognitive Fit: HistGBM(55%) + MLP(45%) → Match / Excel / Struggle
• Dropout Risk: Logistic Regression penalty (% attrition risk)
• Prerequisite Gating: Knowledge Graph DAG (60+ topics)
